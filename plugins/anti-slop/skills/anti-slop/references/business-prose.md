# Slop in business prose

Applies to: email, offer, proposal, LinkedIn post/reply, blog, column, docs,
landing copy, release notes.

## Openers — the highest-signal position

The first sentence carries the strongest tell — generated text opens generically before it commits to a subject. Deletion is the strongest fix; a draft that opens with its second paragraph is usually improved.

| Never | Instead |
|---|---|
| "In today's digital age / era" | the actual year, or nothing |
| "In the ever-evolving world of X" | the specific change: "since the API broke in March" |
| "Let's delve into / dive into" | start with the finding |
| "When it comes to X" | "X" |
| "As a professional" | the actual role and its scope |

## Verb inflation

| Never | Instead |
|---|---|
| harness | use |
| leverage | use |
| unleash | release, start, ship |
| elevate | improve, raise |
| showcase | show |
| underscore, underpin | support, rest on |
| revolutionize | replace, change |
| embark on | start |
| navigate (a challenge) | solve, handle, get through |
| unlock / unveil the secrets | explain, show |

## Hype adjectives

Banned unless concrete evidence sits on the same page.

`seamless` · `cutting-edge` · `transformative` · `game changer` ·
`ever-evolving` · `everchanging` · `groundbreaking` · `robust` ·
`tailored` · `holistic`

For German drafts this file is not enough — German inflects and half its
tells are ordinary words. Read [german-prose.md](german-prose.md).

## Filler intensifiers

Words that add emphasis without adding information. Each one is a hole where a
number belongs.

`meticulous / meticulously` · `intricate` · `intricacies` · `complexities` ·
`nuances` · `vibrant` · `palpable` · `crucial` · `vital` · `countless` ·
`insights` · `daunting` · `insurmountable` · `unwavering`

> "meticulous analysis" → "we checked all 340 rows"
> "countless hours" → "eleven days"

## Connective padding

Signals structure the sentence does not have.

`moreover` · `furthermore` · `thus` · `on the other hand` ·
`as previously mentioned` · `not only … but also` · `it is advisable` ·
`it's essential to` · `you may want to` · `there are a few considerations`

Most are deletable. `moreover` and `furthermore` almost always mean "and".

## Summary and hedge tells

`in conclusion` · `in summary` · `to summarize` · `to put it simply` ·
`it's important to note` · `it's important to remember` · `it's worth noting that`

A closing paragraph that summarizes what the reader just read is itself the tell.
Close with the next step or a position, not a recap.

## Abstraction nouns

Generic containers where a specific noun belongs.

`landscape` · `realm` · `journey` · `world of` · `in the realm of` ·
`ecosystem` · `space` (as in "the AI space") · `adaptability` · `resilience` ·
`inclusivity` · `belongingness` · `interconnectedness`

> "the security landscape" → "our threat model"
> "the AI space" → "the four vendors we evaluated"

## Checking order

1. Read the first and last sentence in isolation — that is where slop concentrates.
2. Grep the draft against the slop list (command in SKILL.md).
3. For each hit ask: does removing this word lose information? If no, remove it.
   If yes, it was carrying meaning and stays.
